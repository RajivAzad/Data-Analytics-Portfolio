**1.Exploratory Data Analysis (EDA) with the Sales Dataset using Pandas,and Matplotlib Seaborn**.

**Overview**

This project demonstrates fundamental data analysis and visualization techniques using Python. The analysis is performed on a sales dataset to explore trends, identify patterns, detect outliers, and generate business insights.

**Visualizations**

The project generates:

Sales Distribution Histogram, Quantity vs Sales Scatter Plot, Sales Trend Line Chart, Sales Outlier Detection Plot, Correlation Heatmap

**Key Insights**

Understand overall sales performance, identify unusual sales outliers, evaluate relationships between sales and quantity sold, compare product category performance, analyse country-wise sales patterns.

**Learning Outcomes**

Through this project, you will learn:

Data cleaning with Pandas
,Exploratory Data Analysis (EDA)
,Data visualization using Matplotlib and Seaborn
,Correlation analysis
,Group By operations
,Pivot table creation
,Business data reporting techniques

**2.Predicting House Prices Using Multiple Linear Regression and Random Forest**

**Introduction**

In this project, I analyzed a real estate dataset to predict house prices using two supervised machine learning techniques: Multiple Linear Regression (MLR) and Random Forest Regression. 
The project involved:
Data cleaning and preprocessing, Exploratory Data Analysis (EDA),feature relationship analysis, building a Multiple Linear Regression model, building a Random Forest Regressor ,Model evaluation and comparison, and house price prediction based on property characteristics

**Exploratory Data Analysis (EDA)**

The EDA process included:
Checking data types and missing values, generating descriptive statistics, visualizing feature distributions, analyzing correlations between variables, identifying potential outliers, and examining the relationship between house features and price

**Key visualizations:**

Correlation heatmap, price distribution histogram, scatter plots of price against numerical features.

**Results**

The Multiple Linear Regression outperformed Random Forest model by capturing complex relationships between features and price, resulting in improved prediction accuracy.
